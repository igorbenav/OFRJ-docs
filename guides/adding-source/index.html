Adicionar Fonte de Dados¶

Guia passo a passo para integrar uma nova fonte de dados ao pipeline.

Visão Geral¶

1. Criar o Loader Python¶

Crie um novo arquivo em src/ingestion/loaders/:

# src/ingestion/loaders/nova_fonte.py
from pathlib import Path

import pandas as pd

from src.ingestion.config import config
from src.ingestion.db import load_dataframe


def read_nova_fonte(file_path: Path) -> pd.DataFrame:
    """Lê o arquivo fonte e retorna um DataFrame."""
    return pd.read_csv(
        file_path,
        sep=";",           # ajuste conforme o formato
        encoding="utf-8",  # ajuste conforme o encoding
        dtype=str,          # preserva valores originais
    )


async def load_nova_fonte() -> dict[str, int]:
    """Carrega a nova fonte no schema raw."""
    results: dict[str, int] = {}

    file_path = config.data_dir / "nova_fonte" / "arquivo.csv"
    if not file_path.exists():
        print(f"Arquivo não encontrado: {file_path}, pulando...")
        return results

    df = read_nova_fonte(file_path)
    count = await load_dataframe(df, "nova_fonte_tabela", schema="raw")
    results["nova_fonte_tabela"] = count

    return results

Para arquivos grandes (> 500MB)¶

Use processamento em chunks como o loader do SINAN:

def read_nova_fonte_chunks(file_path: Path, chunk_size: int):
    """Generator que lê o arquivo em chunks."""
    for chunk in pd.read_csv(file_path, chunksize=chunk_size, dtype=str):
        # Aplicar filtros aqui (ex: filtrar por UF)
        filtered = chunk[chunk["uf"] == "33"]
        if not filtered.empty:
            yield filtered

2. Registrar o Loader¶

Em src/ingestion/loaders/__init__.py¶

from src.ingestion.loaders.nova_fonte import load_nova_fonte

Em src/ingestion/main.py¶

Adicione ao dicionário SOURCES:

SOURCES = {
    "tjrj": load_tjrj,
    "sinan": load_sinan,
    "isp": load_isp,
    "sinesp": load_sinesp,
    "reference": load_reference_data,
    "nova_fonte": load_nova_fonte,  # adicionar aqui
}

Testar a ingestão¶

./scripts/ingest.sh nova_fonte

3. Criar o Modelo Staging¶

Crie o modelo dbt em dbt_project/models/staging/nova_fonte/:

-- dbt_project/models/staging/nova_fonte/stg_nova_fonte__tabela.sql

with source as (
    select * from {{ source('raw', 'nova_fonte_tabela') }}
),

renamed as (
    select
        -- Chave única
        coluna_id as record_id,

        -- Campos limpos
        trim(upper(nome)) as nome,
        to_date(data_campo, 'YYYY-MM-DD') as data_evento,

        -- Campos decodificados (usar macros existentes se aplicável)
        {{ map_sexo('sexo') }} as sexo_nome,

        -- Metadados
        _loaded_at as loaded_at

    from source
    where coluna_id is not null
)

select * from renamed

4. Documentar no Schema YAML¶

Adicione a fonte e o modelo em dbt_project/models/staging/_stg.yml:

sources:
  - name: raw
    tables:
      # ... tabelas existentes ...
      - name: nova_fonte_tabela
        description: Descrição da nova fonte de dados.

models:
  # ... modelos existentes ...
  - name: stg_nova_fonte__tabela
    description: Dados limpos da nova fonte.
    columns:
      - name: record_id
        description: Identificador único.
        tests:
          - unique
          - not_null

5. Executar e Testar¶

# Rodar apenas o novo modelo
./scripts/dbt-run.sh stg_nova_fonte__tabela

# Testar
./scripts/dbt-test.sh

Checklist¶

  • Loader Python criado em src/ingestion/loaders/
  • Loader registrado em __init__.py e main.py
  • Ingestão testada com ./scripts/ingest.sh nova_fonte
  • Modelo staging criado em dbt_project/models/staging/
  • Fonte e modelo documentados em _stg.yml
  • Testes unique e not_null na chave primária
  • dbt run e dbt test passam
