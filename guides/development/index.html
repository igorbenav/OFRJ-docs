Desenvolvimento¶

Ferramentas¶

Python¶

# Lint
uv run ruff check src/

# Formatação automática
uv run ruff format src/

# Type checking (modo strict)
uv run mypy src/

Configuração do ruff em pyproject.toml:

  • Target: Python 3.12
  • Linha máxima: 88 caracteres
  • Regras: pycodestyle, pyflakes, isort, flake8-bugbear, pyupgrade, pathlib, simplify

dbt¶

# Validar sintaxe dos modelos
uv run dbt parse

# Rodar modelos
./scripts/dbt-run.sh                    # todos
./scripts/dbt-run.sh staging            # só staging
./scripts/dbt-run.sh +fct_court_case    # fato + dependências

# Testes
./scripts/dbt-test.sh

# Documentação dbt (auto-gerada)
./scripts/dbt-docs.sh
# Serve em http://localhost:8080

Documentação (Zensical)¶

# Servir documentação localmente
uv run zensical serve
# Acesse http://localhost:8000

# Build estático
uv run zensical build
# Gera em site/

Estrutura de Código Python¶

Convenções¶

  • Async: toda a camada de banco é assíncrona (async/await com asyncpg)
  • Tipos: mypy strict, todas as funções tipadas, sem Any implícito
  • Configuração: singleton config importado de src.ingestion.config
  • Loaders: cada fonte em seu próprio módulo, exportados via __init__.py
  • Retorno: loaders retornam dict[str, int] (tabela → contagem)

Padrão de um Loader¶

async def load_xxx() -> dict[str, int]:
    results: dict[str, int] = {}

    file_path = config.data_dir / "subdir" / "arquivo.csv"
    if not file_path.exists():
        print(f"Arquivo não encontrado: {file_path}, pulando...")
        return results

    df = read_xxx(file_path)
    count = await load_dataframe(df, "tabela_raw", schema="raw")
    results["tabela_raw"] = count

    return results

Queries úteis¶

-- Listar tabelas por schema
SELECT schemaname, tablename
FROM pg_tables
WHERE schemaname IN ('raw', 'staging', 'marts')
ORDER BY schemaname, tablename;

-- Contagem de linhas por tabela
SELECT schemaname, relname, n_live_tup
FROM pg_stat_user_tables
WHERE schemaname IN ('raw', 'staging', 'marts')
ORDER BY n_live_tup DESC;

-- Verificar uma tabela específica
SELECT * FROM marts.dim_location LIMIT 10;
