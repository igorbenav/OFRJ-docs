Camada Raw¶

Dados brutos carregados pela ingestão Python no schema raw. Todas as colunas são preservadas como TEXT (exceto tipos numéricos óbvios). Uma coluna _loaded_at TIMESTAMP é adicionada automaticamente.

raw.tjrj_feminicidio¶

Processos judiciais de feminicídio do TJRJ.

Coluna Tipo Descrição
_id TEXT Identificador único do processo
numeroprocesso TEXT Número CNJ do processo
_source_codclasse TEXT Código da classe processual
_source_nomeclasse TEXT Nome da classe processual
_source_grau TEXT Grau/instância (G1, G2, JE, TR)
_source_siglajustica TEXT Sigla da justiça (TJRJ)
_source_nomeorgaojulgador TEXT Nome do órgão julgador
_source_dataajuizamento TEXT Data de ajuizamento (formato variável)
_source_atualizacao TEXT Data de última atualização
_source_assuntos TEXT JSON com tipos penais e códigos
_loaded_at TIMESTAMP Timestamp de carga

raw.tjrj_violencia_domestica¶

Mesmo schema que raw.tjrj_feminicidio.

raw.tjrj_medida_protetiva / concedida / denegada / revogada¶

Mesmo schema. As 4 tabelas de medidas protetivas compartilham a mesma estrutura.

raw.sinan_notificacao¶

Notificações de violência do SINAN. ~160 colunas. As principais:

Coluna Tipo Descrição
id_agravo TEXT Código do agravo notificado
dt_notific TEXT Data da notificação
sg_uf_not TEXT UF de notificação (33 = RJ)
id_municip TEXT Código IBGE do município
dt_ocor TEXT Data da ocorrência
dt_nasc TEXT Data de nascimento da vítima
cs_sexo TEXT Sexo (M, F, I)
cs_raca TEXT Raça/cor (1–5, 9)
cs_escol_n TEXT Escolaridade (0–10)
cs_estcivil TEXT Estado civil (1–5, 9)
local_ocor TEXT Código do local de ocorrência
viol_fisic TEXT Violência física (1 = sim)
viol_psico TEXT Violência psicológica (1 = sim)
viol_sexu TEXT Violência sexual (1 = sim)
viol_tort TEXT Tortura (1 = sim)
viol_traf TEXT Tráfico (1 = sim)
viol_finan TEXT Violência financeira (1 = sim)
viol_negli TEXT Negligência (1 = sim)
viol_outr TEXT Outra violência (1 = sim)
rel_conj TEXT Agressor é cônjuge (1 = sim)
rel_namo TEXT Agressor é namorado(a) (1 = sim)
rel_pai TEXT Agressor é pai (1 = sim)
rel_mae TEXT Agressor é mãe (1 = sim)
rel_cuida TEXT Agressor é cuidador (1 = sim)
rel_patrao TEXT Agressor é patrão (1 = sim)
rel_irmao TEXT Agressor é irmão (1 = sim)
rel_conhec TEXT Agressor é amigo/conhecido (1 = sim)
rel_desco TEXT Agressor é desconhecido (1 = sim)
rel_outros TEXT Outro relacionamento (1 = sim)
evolucao TEXT Desfecho (1=Cura, 2=Óbito violência, 3=Óbito outras, 9=Ignorado)
viol_repet TEXT Violência de repetição (1 = sim)
_loaded_at TIMESTAMP Timestamp de carga

Colunas omitidas

O SINAN possui ~160 colunas. Apenas as principais utilizadas no pipeline estão listadas aqui.

raw.sim_obito_externo¶

Declarações de óbito por causas externas do SIM/DATASUS. ~131 colunas. As principais:

Coluna Tipo Descrição
contador TEXT Contador sequencial (parcial, coalesce com CONTADOR)
tipobito TEXT Tipo do óbito (2 = não fetal)
dtobito TEXT Data do óbito (formato DDMMAAAA)
sexo TEXT Sexo (1 = masculino, 2 = feminino, 0/9 = ignorado)
racacor TEXT Raça/cor (1–5, 9)
idade TEXT Idade DATASUS (4xxx = anos, 3xx = meses, 2xx = dias)
dtnasc TEXT Data de nascimento (formato DDMMAAAA)
estciv TEXT Estado civil (1–5, 9)
esc TEXT Escolaridade (formato antigo)
esc2010 TEXT Escolaridade (formato 2010+)
ocup TEXT Código CBO da ocupação
codmunres TEXT Código IBGE do município de residência (6 ou 7 dígitos)
codmunocor TEXT Código IBGE do município de ocorrência (6 ou 7 dígitos)
lococor TEXT Local de ocorrência (1=hospital, 2=outro saúde, 3=domicílio, 4=via pública, 5=outros)
causabas TEXT Causa básica do óbito (código CID-10)
causabas_o TEXT Causa básica original (antes de correção)
linhaa TEXT Causa na linha A (CID-10)
linhab TEXT Causa na linha B (CID-10)
linhac TEXT Causa na linha C (CID-10)
linhad TEXT Causa na linha D (CID-10)
circobito TEXT Circunstância (1=acidente, 2=suicídio, 3=homicídio, 4=outros, 9=ignorado)
necropsia TEXT Necropsia (1=sim, 2=não, 9=ignorado)
horaobito TEXT Hora do óbito
fonte TEXT Fonte da informação
_loaded_at TIMESTAMP Timestamp de carga

Colunas omitidas

O SIM possui ~131 colunas. Apenas as principais utilizadas no pipeline estão listadas aqui. A coluna CONTADOR (maiúscula) é coalesce com contador (minúscula) no loader (mudança de schema entre 2005 e 2006).

ano_mes TEXT Mês de referência (formato YYYY-MM)

raw.censo_familias_mulheres¶

Famílias chefiadas por mulheres do Censo 2022 em formato long (4 dimensões consolidadas).

Coluna Tipo Descrição
cod_municipio TEXT Código IBGE (7 dígitos, vazio para instrução)
municipio TEXT Nome do município (com "(RJ)")
dimensao TEXT cor_raca, faixa_etaria, nivel_instrucao, ou composicao
categoria TEXT Categoria dentro da dimensão
quantidade TEXT Número de domicílios/famílias
_loaded_at TIMESTAMP Timestamp de carga

raw.cadunico_mulheres_cor_raca¶

Mulheres chefes de família por cor/raça (formato wide).

Coluna Tipo Descrição
branca TEXT Quantidade — Branca
preta TEXT Quantidade — Preta
amarela TEXT Quantidade — Amarela
parda TEXT Quantidade — Parda
indígena TEXT Quantidade — Indígena
sem_resposta TEXT Quantidade — Sem Resposta
total TEXT Total
municipio TEXT Nome do município
ibge TEXT Código IBGE (7 dígitos)
_loaded_at TIMESTAMP Timestamp de carga

raw.cadunico_mulheres_faixa_etaria¶

Mulheres chefes de família por faixa etária (formato wide, 14 colunas de faixa).

Mesmo padrão que cor_raca, com colunas entre_0_e_4, entre_5_a_6, ..., maior_que_65, sem_resposta.

raw.cadunico_mulheres_renda¶

Mulheres chefes de família por faixa de renda familiar (formato wide).

Mesmo padrão, com colunas até_1_s.m., entre_1_e_2_s.m., entre_2_e_3_s.m., acima_de_3_s.m., sem_resposta.

raw.populacao_municipal¶

População do Censo 2022 por município em formato long (2 dimensões consolidadas).

Coluna Tipo Descrição
cod_municipio TEXT Código IBGE (7 dígitos, vazio para raça)
municipio TEXT Nome do município (com "(RJ)")
dimensao TEXT sexo_idade, sexo_total, ou raca_mulheres
sexo TEXT M ou F
categoria TEXT Faixa etária ou categoria de raça
populacao TEXT Contagem populacional
_loaded_at TIMESTAMP Timestamp de carga

raw.ibge_indicador_municipal¶

Indicadores municipais do IBGE em formato long (3 indicadores × 92 municípios).

Coluna Tipo Descrição
cod_municipio TEXT Código IBGE do município (7 dígitos)
municipio TEXT Nome do município (ex: "Angra dos Reis (RJ)")
indicador TEXT Nome do indicador (nascidos_vivos, obitos_infantis, pib_mil_reais)
ano TEXT Ano de referência
valor TEXT Valor numérico (0 para valores "-" do IBGE)
_loaded_at TIMESTAMP Timestamp de carga

2018 ... 2025 TEXT Contagem de ocorrências por ano

tipo_crime TEXT Tipo de evento criminal

vitimas_femininas TEXT Contagem de vítimas femininas

Nomes de colunas

Os nomes exatos das colunas podem variar entre anos do SINESP. Os nomes acima são representativos.

raw.justica_tj_* (5 tabelas)¶

Indicadores anuais do TJ-RJ — uma tabela por contexto, schemas próprios.

  • raw.justica_tj_violencia_domestica: ano, acervo, distribuidos
  • raw.justica_tj_feminicidio: ano, acervo, distribuidos, plenários_do_juri, tempo_medio_do_plenário, audiências_realizadas, audiências_futuras_agendadas, sentenças, prisões
  • raw.justica_tj_medidas_protetivas: ano, medidas_protetivas, deferidas, concedidas_em_parte, indeferidas
  • raw.justica_tj_cejuvida: ano, abrigamentos
  • raw.justica_tj_projeto_violeta: ano, projeto_violeta

Período: 2015-2026. Dado estadual, sem município.
