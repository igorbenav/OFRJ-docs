Dimensões¶

Tabelas no schema marts que fornecem contexto para as tabelas de fato.

dim_date¶

Dimensão de data com grão diário, cobrindo 1996-01-01 a 2030-12-31.

Gerada por: dbt_utils.date_spine()

Coluna Tipo Descrição Testes
date_sk INT Chave substituta (formato YYYYMMDD) unique, not_null
full_date DATE Data completa unique, not_null
year INT Ano (4 dígitos)
quarter INT Trimestre (1–4)
month INT Mês (1–12)
week_of_year INT Semana ISO (1–53)
day_of_month INT Dia do mês (1–31)
day_of_week INT Dia da semana (0=Domingo, 6=Sábado)
month_name TEXT Nome do mês em português
day_name TEXT Nome do dia em português
is_weekend BOOLEAN Sábado ou domingo
year_month TEXT Período ano-mês (YYYY-MM)

dim_location¶

92 municípios do Rio de Janeiro com hierarquia geográfica e dados censitários.

Fontes: raw.ibge_municipio + raw.ibge_censo + raw.legislacao_municipal

Coluna Tipo Descrição Testes
location_sk INT Chave substituta (ROW_NUMBER) unique, not_null
ibge_code TEXT Código IBGE do município (7 dígitos) unique, not_null
ibge_code_6 TEXT Código IBGE sem dígito verificador (6 dígitos, para joins com SIM/DATASUS)
municipality_name TEXT Nome oficial
municipality_name_normalized TEXT Nome uppercase sem acentos (para joins)
immediate_region_code TEXT Código da região imediata IBGE
immediate_region_name TEXT Nome da região imediata
intermediate_region_code TEXT Código da região intermediária IBGE
intermediate_region_name TEXT Nome da região intermediária
state_code TEXT Código da UF (33)
state_name TEXT Nome do estado (Rio de Janeiro)
population_2022 INT População (Censo 2022)
area_km2 FLOAT Área territorial (km²)
density_hab_km2 FLOAT Densidade demográfica (hab/km²)
has_legislation BOOLEAN Possui legislação específica sobre violência contra a mulher

dim_crime_type¶

15 tipos de crime. Tabela estática com VALUES.

Coluna Tipo Descrição Testes
crime_type_sk INT Chave substituta unique, not_null
crime_code INT Código do assunto TJRJ
crime_name TEXT Nome do tipo penal
crime_category TEXT Categoria (feminicídio, violência doméstica, violência sexual, outros)
is_feminicide BOOLEAN É feminicídio
is_domestic_violence BOOLEAN É violência doméstica
is_sexual_violence BOOLEAN É violência sexual

dim_relationship¶

19 tipos de relacionamento vítima-agressor. Tabela estática com VALUES.

Coluna Tipo Descrição Testes
relationship_sk INT Chave substituta unique, not_null
relationship_code TEXT Código interno
relationship_name TEXT Nome em português
relationship_name_en TEXT Nome em inglês
relationship_category TEXT Categoria (parceiro íntimo, família, conhecido)
is_intimate_partner BOOLEAN É parceiro íntimo
is_family_member BOOLEAN É familiar
source_system TEXT Sistema de origem (ISP, SINAN, ambos)

dim_outcome¶

Desfechos de casos e notificações. Tabela estática com VALUES.

Coluna Tipo Descrição Testes
outcome_sk INT Chave substituta (99 = desconhecido) unique, not_null
outcome_code TEXT Código do desfecho
outcome_name TEXT Nome em português
outcome_name_en TEXT Nome em inglês
source_system TEXT Sistema de origem (tjrj, sinan)

Valores TJRJ: concedida, parcial, denegada, revogada, prorrogada, pendente

Valores SINAN: Cura (1), Óbito por Violência (2), Óbito por Outras Causas (3), Ignorado (9)

dim_location_type¶

Tipos de local de ocorrência. Tabela estática com VALUES.

Coluna Tipo Descrição Testes
location_type_sk INT Chave substituta unique, not_null
location_type_code TEXT Código (SINAN: 1–99; ISP: texto)
location_type_name TEXT Nome em português
location_type_name_en TEXT Nome em inglês
location_type_category TEXT Categoria
source_system TEXT Sistema de origem (sinan, isp, sim)

dim_victim_profile¶

Dimensão conformada de perfil demográfico. Gerada por cross-join de faixas etárias × sexo × raça.

Coluna Tipo Descrição Testes
victim_profile_sk TEXT Chave substituta (hash MD5) unique, not_null
age_range_code TEXT Código da faixa etária
age_range_name TEXT Nome da faixa (ex: "Jovem 18-29")
sex_code TEXT Código do sexo (M, F, I, X)
sex_name TEXT Nome (Masculino, Feminino, Ignorado, Não Informado)
race_code TEXT Código raça/cor (1–5, 9, X)
race_name TEXT Nome (Branca, Preta, Amarela, Parda, Indígena, etc.)
is_female BOOLEAN Sexo feminino
is_minor BOOLEAN Menor de 18 anos
is_elderly BOOLEAN 60 anos ou mais

Faixas etárias:

Código Faixa Idade
crianca_0_11 Criança 0–11
adolescente_12_17 Adolescente 12–17
jovem_18_29 Jovem 18–29
adulto_30_44 Adulto 30–44
adulto_45_59 Adulto 45–59
idoso_60_plus Idoso 60+
nao_informado Não informado -

dim_case_flags¶

Junk dimension com todas as combinações de 3 flags booleanos (2³ = 8 linhas).

Coluna Tipo Descrição Testes
case_flags_sk TEXT Chave substituta (hash MD5) unique, not_null
lei_maria_penha BOOLEAN Aplicação da Lei Maria da Penha
is_repeat_violence BOOLEAN Violência de repetição
is_flagrante BOOLEAN Prisão em flagrante (uso futuro)
flags_summary TEXT Resumo legível (ex: "LMP + Reincidência")

dim_care_facility¶

442 equipamentos da rede de proteção. Conectada a fct_taxa_municipal (taxa de equipamentos por 100K hab).

Fonte: raw.rede_protecao

Coluna Tipo Descrição Testes
facility_sk INT Chave substituta (ROW_NUMBER) unique, not_null
facility_name TEXT Nome da instituição
facility_type TEXT Tipo de serviço
facility_category TEXT Categoria
is_public BOOLEAN Se é público
municipio TEXT Município
region TEXT Região do estado
address TEXT Endereço
phone TEXT Telefone
email TEXT E-mail
geolocation_url TEXT URL de geolocalização
operating_hours TEXT Horário de funcionamento
has_shelter_referral TEXT Encaminha para abrigo
notes TEXT Observações
