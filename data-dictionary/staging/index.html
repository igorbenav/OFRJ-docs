Camada Staging¶

Views no schema staging que limpam, tipam e normalizam os dados brutos.

stg_tjrj__feminicidio¶

Processos de feminicídio limpos. Mesmo schema para stg_tjrj__violencia_domestica (diferem apenas no valor de case_type).

Coluna Tipo Descrição Testes
case_id TEXT Identificador único do processo unique, not_null
case_number TEXT Número CNJ do processo
class_code TEXT Código da classe processual
class_name TEXT Nome da classe processual
court_instance TEXT Instância: G1, G2, JE, TR
court TEXT Sigla da justiça (TJRJ)
court_name TEXT Nome do órgão julgador
filing_date DATE Data de ajuizamento (normalizada)
last_update_at TIMESTAMP Última atualização
assuntos_raw TEXT JSON com tipos penais
case_type TEXT 'feminicidio' ou 'violencia_domestica'
loaded_at TIMESTAMP Timestamp de carga

stg_tjrj__medida_protetiva¶

Pedidos de medidas protetivas com desfecho deduplicado.

Coluna Tipo Descrição Testes
case_id TEXT Identificador único do pedido unique, not_null
case_number TEXT Número CNJ
court_instance TEXT Instância
court TEXT Sigla da justiça
court_name TEXT Órgão julgador
filing_date DATE Data do pedido
last_update_at TIMESTAMP Última atualização
outcome TEXT Desfecho: concedida, denegada, revogada, pendente
loaded_at TIMESTAMP Timestamp de carga

stg_sinan__notificacao¶

Notificações de violência com campos decodificados.

Coluna Tipo Descrição Testes
notification_row_id INT ID sintético único (ROW_NUMBER) unique, not_null
notification_id TEXT ID composto (agravo + data + município)
notification_date DATE Data da notificação
occurrence_date DATE Data da ocorrência
death_date DATE Data do óbito (se houver)
notification_municipality_code TEXT Código IBGE do município de notificação
occurrence_municipality_code TEXT Código IBGE do município de ocorrência
victim_sex TEXT Código do sexo (M, F, I)
victim_sex_name TEXT Nome decodificado (Masculino, Feminino, Ignorado)
victim_birth_year TEXT Ano de nascimento
victim_race_code TEXT Código raça/cor (1–5, 9)
victim_race_name TEXT Nome decodificado (Branca, Preta, Parda, etc.)
victim_education_code TEXT Código escolaridade (0–10)
victim_education_name TEXT Nome decodificado
victim_marital_status_code TEXT Código estado civil (1–5, 9)
victim_marital_status_name TEXT Nome decodificado
location_type_code TEXT Código do local de ocorrência
outcome_code TEXT Código de evolução (1–3, 9)
has_physical_violence BOOLEAN Violência física
has_psychological_violence BOOLEAN Violência psicológica
has_torture_violence BOOLEAN Tortura
has_sexual_violence BOOLEAN Violência sexual
has_trafficking_violence BOOLEAN Tráfico
has_financial_violence BOOLEAN Violência financeira
has_neglect_violence BOOLEAN Negligência
has_other_violence BOOLEAN Outra violência
rel_spouse BOOLEAN Agressor é cônjuge
rel_partner BOOLEAN Agressor é namorado(a)
rel_father BOOLEAN Agressor é pai
rel_mother BOOLEAN Agressor é mãe
rel_caretaker BOOLEAN Agressor é cuidador
rel_employer BOOLEAN Agressor é patrão
rel_sibling BOOLEAN Agressor é irmão
rel_acquaintance BOOLEAN Agressor é amigo/conhecido
rel_stranger BOOLEAN Agressor é desconhecido
rel_other BOOLEAN Outro relacionamento
is_repeat_violence BOOLEAN Violência de repetição

stg_sim__obito_externo¶

Óbitos por causas externas com campos decodificados e classificados.

Coluna Tipo Descrição Testes
death_row_id INT ID sintético único (ROW_NUMBER) unique, not_null
death_date DATE Data do óbito
death_time TEXT Hora do óbito
cause_code TEXT Código CID-10 da causa básica (ex: X95, Y09)
cause_group TEXT Primeiros 3 caracteres do CID-10 (agrupamento)
cause_original TEXT Causa original (antes de revisão)
cause_line_a TEXT Causa na linha A
cause_line_b TEXT Causa na linha B
cause_line_c TEXT Causa na linha C
cause_line_d TEXT Causa na linha D
circumstance_code TEXT Código da circunstância (1–4, 9)
circumstance_name TEXT Nome: Acidente, Suicídio, Homicídio, Outros, Ignorado
is_assault BOOLEAN CID-10 X85–Y09 (agressão/homicídio)
is_undetermined_intent BOOLEAN CID-10 Y10–Y34 (intenção indeterminada)
is_suicide BOOLEAN CID-10 X60–X84 (autolesão intencional)
is_accident BOOLEAN CID-10 V01–X59 (acidente)
victim_sex TEXT Código padronizado (M, F, I, X)
victim_sex_name TEXT Nome: Masculino, Feminino, Ignorado
victim_age INT Idade em anos (decodificado do formato DATASUS)
victim_birth_date DATE Data de nascimento
victim_race_code TEXT Código raça/cor (1–5, 9)
victim_race_name TEXT Nome decodificado
victim_education_code TEXT Código escolaridade (ESC2010 ou ESC)
victim_education_name TEXT Nome decodificado
victim_marital_status_code TEXT Código estado civil
victim_marital_status_name TEXT Nome decodificado
victim_occupation_code TEXT Código CBO da ocupação
death_location_code TEXT Código do local do óbito (1–5, 9)
death_location_name TEXT Nome: Hospital, Domicílio, Via Pública, etc.
residence_municipio_code TEXT Código IBGE 6 dígitos (residência)
occurrence_municipio_code TEXT Código IBGE 6 dígitos (ocorrência)
had_necropsy BOOLEAN Se houve necropsia

stg_isp__feminicidio¶

Registros policiais de feminicídio com campos normalizados.

Coluna Tipo Descrição Testes
record_id TEXT Identificador do caso (controle) not_null
uuid TEXT Identificador único da vítima unique, not_null
crime_date DATE Data do crime
report_date DATE Data do registro policial
crime_time TEXT Horário (validado HH:MM ou HH:MM:SS)
crime_municipio TEXT Município (normalizado, sem acentos)
crime_bairro TEXT Bairro
location_type TEXT Tipo de local
cisp TEXT Circunscrição policial
aisp TEXT Área integrada de segurança
risp TEXT Região integrada de segurança
victim_sex TEXT Sexo (texto original)
victim_sex_code TEXT Código padronizado (M, F, X)
victim_age INT Idade
victim_race TEXT Raça/cor (texto original)
victim_race_code TEXT Código IBGE padronizado (1–5, X)
relationship TEXT Relacionamento vítima-agressor
lei_maria_penha BOOLEAN Aplicação da Lei Maria da Penha

unknown_sex_victims INT Vítimas com sexo não informado
total_victims INT Total de vítimas
total_occurrences INT Total de ocorrências
source_year TEXT Ano do arquivo de origem
