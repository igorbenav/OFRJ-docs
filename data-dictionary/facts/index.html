Fatos¶

Tabelas de fato no schema marts. Divididas em transacionais (1 evento = 1 linha) e periódicas (snapshots agregados).

Fatos Transacionais¶

fct_court_case¶

Processos judiciais de feminicídio e violência doméstica. Grão: 1 por processo.

Fontes: stg_tjrj__feminicidio UNION ALL stg_tjrj__violencia_domestica

Deduplicação: se um case_id aparece nas duas fontes, feminicídio vence.

Coluna Tipo Descrição Testes
case_sk TEXT Chave substituta (hash MD5) unique, not_null
case_id TEXT Chave natural do TJRJ
case_number TEXT Número CNJ (pode vincular com fct_medida_protetiva)
case_type TEXT feminicidio ou violencia_domestica
class_code TEXT Código da classe processual
class_name TEXT Nome da classe processual
court_instance TEXT Instância (G1, G2, JE, TR)
court_name TEXT Nome do órgão julgador
filing_date_sk INT FK → dim_date (data de ajuizamento) relationships
last_update_date_sk INT FK → dim_date (última atualização)
filing_date DATE Data de ajuizamento (referência)
assuntos_raw TEXT JSON com tipos penais (usado pela bridge)

fct_medida_protetiva¶

Pedidos de medidas protetivas de urgência. Grão: 1 por pedido.

Fonte: stg_tjrj__medida_protetiva

Coluna Tipo Descrição Testes
measure_sk TEXT Chave substituta (hash MD5) unique, not_null
case_id TEXT Chave natural do TJRJ
case_number TEXT Número CNJ (pode vincular com fct_court_case)
court_instance TEXT Instância
court_name TEXT Órgão julgador
outcome_sk INT FK → dim_outcome (fallback: 99)
outcome TEXT Desfecho (referência)
filing_date_sk INT FK → dim_date
filing_date DATE Data do pedido (referência)

fct_obito_externo¶

Óbitos por causas externas no RJ (SIM/DATASUS). Grão: 1 por óbito. Período: 1996–2024.

Fonte: stg_sim__obito_externo

Coluna Tipo Descrição Testes
death_sk TEXT Chave substituta (hash MD5) unique, not_null
death_row_id INT ID sintético original
death_date_sk INT FK → dim_date (data do óbito)
residence_location_sk INT FK → dim_location (município de residência)
occurrence_location_sk INT FK → dim_location (município de ocorrência)
death_location_type_sk INT FK → dim_location_type (local do óbito)
victim_profile_sk TEXT FK → dim_victim_profile
death_date DATE Data do óbito (referência)
death_time TEXT Hora do óbito
cause_code TEXT Código CID-10 da causa básica
cause_group TEXT Grupo CID-10 (3 caracteres)
cause_original TEXT Causa original (antes de revisão)
cause_line_a TEXT Causa na linha A
cause_line_b TEXT Causa na linha B
cause_line_c TEXT Causa na linha C
cause_line_d TEXT Causa na linha D
circumstance_code TEXT Código da circunstância
circumstance_name TEXT Acidente, Suicídio, Homicídio, Outros, Ignorado
is_assault BOOLEAN Agressão (CID-10 X85–Y09)
is_undetermined_intent BOOLEAN Intenção indeterminada (CID-10 Y10–Y34)
is_suicide BOOLEAN Suicídio (CID-10 X60–X84)
is_neglect_abandonment BOOLEAN Negligência e abandono (CID-10 Y06)
is_intentional_maltreatment BOOLEAN Maus-tratos intencionais (CID-10 Y07)
is_legal_intervention BOOLEAN Intervenção legal (CID-10 Y35–Y36)
is_accident BOOLEAN Acidente (CID-10 V01–X59)
is_female BOOLEAN Vítima feminina
is_female_homicide BOOLEAN Feminina + agressão (indicador de feminicídio)
victim_sex TEXT Código do sexo (referência)
victim_age INT Idade em anos (referência)
victim_race_code TEXT Raça/cor (referência)
victim_education_code TEXT Escolaridade (referência)
victim_marital_status_code TEXT Estado civil (referência)
had_necropsy BOOLEAN Necropsia realizada
residence_municipio_code TEXT Código IBGE 6 dígitos (residência)
occurrence_municipio_code TEXT Código IBGE 6 dígitos (ocorrência)

Análises principais

  • Feminicídios confirmados: is_female_homicide = true
  • Feminicídios ocultos: is_female = true AND is_undetermined_intent = true (pesquisas indicam que muitos feminicídios são classificados como intenção indeterminada)
  • Subnotificação: comparar contagens com fct_feminicidio_policia (ISP) por município e ano

Coluna Tipo Descrição Testes

fct_taxa_municipal¶

Taxas per capita por município. Grão: Município × Indicador × Ano.

Fonte: Calculado a partir de fct_crime_municipal_anual, fct_notificacao_violencia, fct_ligue_190, dim_care_facility e fct_populacao_municipal

Coluna Tipo Descrição Testes
taxa_sk TEXT Chave substituta (hash MD5) unique, not_null
location_sk INT FK → dim_location relationships
ibge_code_6 TEXT Código IBGE 6 dígitos
ano INT Ano (null para indicadores atemporais)
indicador TEXT Tipo de taxa (ver abaixo)
valor NUMERIC Taxa per capita (por 100.000 habitantes)

Indicadores:

Indicador Descrição Denominador
taxa_feminicidio_100k_mulheres Feminicídios por 100K mulheres População feminina (Censo 2022)
taxa_notificacao_violencia_100k Notificações SINAN por 100K hab População total (Censo 2022)
taxa_chamadas_190_100k Chamadas Ligue 190 por 100K hab População total (Censo 2022)
equipamentos_rede_100k Equipamentos da rede de proteção por 100K hab População total (Censo 2022)
